**Target Domain**: wus.edu.pk - Women University Swabi

## Objective
The objective of this project is to collect publicly available information about the target website using OSINT (Open Source Intelligence) techniques. 
Only publicly available information was collected, and no unauthorized access or attack was performed.

## Tools & Techniques Used
- **Tool 1 - Google Dorking**: To find all pages indexed by Google
    - Query: `site:wus.edu.pk`
- **Tool 2 - Reverse DNS Lookup**: To find IP and server information
- **Tool 3 - Whois Lookup**: To find domain registration details
- **Tool 4 - Shodan / Nmap**: For service and port scanning

## Key Findings
The report includes screenshots and results of:
1. Google indexed pages of WUS
2. Publicly available PDF documents
3. Server IP and location details
4. Open ports and services

## Disclaimer
This project was conducted for educational purposes only. All data collected is publicly available. No ethical guidelines were violated.
